# ConfiBot

ConfiBot is a lightweight local chatbot application built with Python, Gradio, and a local LLM API. It is designed to run on your own machine so your conversations stay private and do not depend on a remote cloud service.

The project includes:

- a Gradio web interface
- model selection between English and Polish assistant profiles
- a local chat wrapper for a running Ollama-compatible backend
- a simple terminal-based chat client as a fallback

## Project structure

- `confibot.py` — main application and Gradio chat UI
- `simple_chat.py` — minimal local LLM client that sends requests to a local chat endpoint
- `graphics/` — branding assets used by the UI
- `requirements.txt` — Python package dependencies
- `venv/` — local virtual environment (generated by Python)

## Features

- Select between different local language models and assistant personalities
- Switch between an English and Polish assistant configuration
- Maintain chat history within the active session
- Run the app locally with no external API key required
- Optionally expose the Gradio interface via a share link

## Requirements

Before running the app, make sure you have:

- Python 3.10+
- pip
- Ollama installed and running locally
- an LLM model downloaded to your local Ollama instance

## Installation

1. Open a terminal in the project folder.
2. Create and activate a virtual environment:

```bash
python -m venv venv
source venv/bin/activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Download Ollama models:

```bash
ollama pull qwen2.5:3b
ollama pull hf.co/second-state/Bielik-4.5B-v3.0-Instruct-GGUF:Q4_K_M
```

## Running the app

Start Ollama in a separate terminals:
```bash
ollama run qwen2.5:3b
ollama run hf.co/second-state/Bielik-4.5B-v3.0-Instruct-GGUF:Q4_K_M
```

and ensure it is listening on:

```text
http://localhost:11434
```

Launch the Gradio app:

```bash
python confibot.py
```

This opens the chatbot interface in your browser.

## Model configuration

The app currently defines two model profiles in `confibot.py`:

- `Ollama (English)` using `qwen2.5:3b`
- `Bielik (Polish)` using a Bielik GGUF model path

You can change these values in the `models` dictionary in `confibot.py` if you want to use different local models or different personality instructions.

## Terminal version

The project also includes a very simple terminal chat client:

```bash
python simple_chat.py
```

This version prompts for a message and prints the model response directly in the terminal.

## Notes

- The app expects a local chat API at `http://localhost:11434/api/chat`.
- If you use a different local backend or different model names, update the configuration in `confibot.py` and `simple_chat.py` accordingly.
- The `share=True` option in `ConfiBot.run()` is enabled in the current version, so the Gradio app can be shared externally if your environment allows it.

## Example use case

This project is well suited for:

- local AI experimentation
- private personal assistant workflows
- testing different open-source models without cloud dependencies
- experimenting with multilingual model prompts and behavior
